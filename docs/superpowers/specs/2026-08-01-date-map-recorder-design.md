# デート記録サイト 設計書

作成日: 2026-08-01

## 目的
デートで行った場所を地図上にピンで記録し、写真・メモ・感想・ジャンルを添えて残す。
あとから「特定の日」「期間」「全部」「ジャンル」「場所名検索」で見返せる、個人用の思い出アプリ。

## 技術構成
- 単一の `index.html`（他ポートフォリオと同じ、ビルド不要の静的サイト）
- 地図: **Leaflet + OpenStreetMap**（無料・APIキー不要）
- データ/写真の保存: **IndexedDB**（ブラウザ内。写真の容量にも耐える）
- サーバー不要。1人（自分の端末）での利用が前提。端末間の共有はしない。

## データモデル
1件の記録 = 1か所の訪問。

```
記録 (record) = {
  id:      一意のID,
  date:    訪問日 (YYYY-MM-DD),
  name:    場所名（お店・施設の名前）,
  genre:   ジャンル,
  lat, lng: 緯度経度,
  memo:    メモ / 感想（自由テキスト）,
  photos:  写真の配列（複数枚、画像データ）
}
```

### ジャンル（初期セット）
ごはん / カフェ / 施設 / 観光 / 買い物 / その他
- ジャンルごとに**ピンの色**を変えて地図上で区別する。

## 画面構成（1画面・レスポンシブ）
- 中央に**地図**、横（スマホでは上下）に**サイドパネル**。
- 上部に **検索ボックス**（登録済みの場所名で検索 → その地点へ移動）。
- **絞り込みバー**:
  - 表示範囲: 「特定の日」/「期間（開始〜終了）」/「全部」
  - ジャンル: 各ジャンルの表示ON/OFF
  - → 条件に合うピンだけ地図に表示。

## 主な操作フロー
1. **記録の追加**: 地図をクリック → 入力フォーム（日付・場所名・ジャンル・メモ・写真）→ 保存 → ピンが立つ。
2. **記録の閲覧**: ピンをクリック → パネルに写真（サムネイル）・メモ・ジャンル・日付を表示。
3. **編集 / 削除**: 閲覧パネルから編集・削除ができる。
4. **検索**: 場所名で検索 → 該当ピンへ地図が移動＆ハイライト。
5. **絞り込み**: 日付/期間/全部 × ジャンルで、表示するピンを切り替え。

## 補助機能
- 写真は複数枚OK。パネルでサムネイル表示。
- **バックアップ**: 全データを JSON で書き出し / 読み込み（端末変更・データ消失対策）。
  写真も含めてエクスポートできるようにする。

## 想定コンポーネント（役割分担）
- 地図表示・ピン管理（Leaflet 制御）
- 記録データの保存/読込（IndexedDB アクセス層）
- 記録の入力/編集フォーム
- 記録の閲覧パネル
- 絞り込み・検索の制御（表示するピンの決定）
- バックアップ（JSON入出力）

## やらないこと（スコープ外）
- 端末間・複数人でのリアルタイム共有
- 地名/住所からの地図検索（ピンはクリックで設置。検索は登録済みの場所名のみ）
- アカウント/ログイン機能
